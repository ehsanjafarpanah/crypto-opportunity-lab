# آزمایشگاه شکار فرصت‌های کریپتو

> روش مستمر برای کشف روایت‌ها و پروژه‌های کریپتویی پیش از فراگیرشدن، با تکیه بر شواهد توسعه‌دهنده‌ها، اپراتورها، کاربران، درآمد و اقتصاد توکن.

**نسخه روش:** 1.0  
**تاریخ شروع:** 2026-11-23  
**آخرین مبنای داده:** 2026-11-23  
**وضعیت:** فعال؛ روش پژوهشی عمومی و قابل‌توسعه

## هدف

پیدا کردن پروژه‌هایی که احتمال دارد بازار هنوز ارزش واقعی یا رشد آینده آن‌ها را کامل قیمت‌گذاری نکرده باشد؛ نه دنبال‌کردن صرف ترندهای شبکه‌های اجتماعی.

هدف تحلیلی: شناسایی فرصت‌های نامتقارن با امکان رشد بالا، از جمله سناریوهای 3x تا 5x در افق 3 تا 6 ماه؛ بدون فرض تضمین بازده و بدون تبدیل هر نامزد به توصیه خرید.

## قواعد کار

1. هر جلسه داده تازه باید با تاریخ و ساعت ثبت شود؛ داده قدیمی با داده امروز مخلوط نشود.
2. هیچ پروژه‌ای فقط به‌خاطر رشد قیمت، ترند X یا تعداد ثبت‌نام/کیف‌پول وارد فهرست اصلی نمی‌شود.
3. سیگنال توسعه‌دهنده، اپراتور، کاربر، درآمد، توکنومیکس و بازار باید جداگانه سنجیده شوند.
4. برای هر ادعا منبع اولیه یا منبع مستقل معتبر ثبت شود.
5. داده‌های پروژه‌محور و ادعاهای خود پروژه با برچسب «خوداظهاری» مشخص شوند.
6. اگر درآمد، نقدشوندگی یا ارزش‌گیری توکن اثبات نشود، پروژه در Watchlist می‌ماند و به وضعیت ورود ارتقا نمی‌یابد.
7. گزارش هر روز باید تغییرات نسبت به آخرین snapshot را نشان دهد؛ بازنویسی بی‌دلیل کل فهرست ممنوع.

## چرخه مستمر

**کشف → اعتبارسنجی → امتیازدهی → بررسی توکن → بررسی بازار → تصمیم → پایش**

هر جلسه جدید:
- کاندیداهای تازه از X، Reddit، GitHub، داشبوردهای اپراتورها و داده‌های آن‌چین پیدا شوند.
- نامزدهای قبلی با داده جدید به‌روزرسانی شوند.
- فرضیه‌های ردشده ثبت شوند تا دوباره وقت تلف نشود.
- فقط تغییرات مهم در WATCHLIST و DECISIONS_LOG ثبت شوند.
- گزارش روزانه از قالب DAILY_LOG_TEMPLATE استفاده کند.

## تعریف وضعیت‌ها

- **Discovery:** سرنخ اولیه؛ هنوز راستی‌آزمایی نشده.
- **Watchlist:** شواهد اولیه وجود دارد، اما یک یا چند شرط مهم ناقص است.
- **Research Priority:** ارزش بررسی عمیق دارد.
- **Entry Candidate:** اقتصاد، عرضه، نقدشوندگی و ساختار بازار قابل دفاع شده‌اند؛ هنوز به معنی خرید نیست.
- **Rejected / Paused:** شواهد منفی یا ریسک غیرقابل‌قبول.
- **Graduated:** پروژه از فاز کشف اولیه خارج شده؛ صرفاً برای جلوگیری از تکرار رصد می‌شود.
